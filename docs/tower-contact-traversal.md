# 足場との接触を中心にしたタワー移動

2026-10-03。タワーの旧rootジャンプ補間を廃止し、`surface-traversal.ts` の独立した制御へ変更。窓辺のジャンプ・玩具・直接操作の入口を保持した。

## ブラウザで見つけた問題

修正前を実GLBと実ルームで再生し、両猫の上り・下り各12枚、計48枚を撮影。床から屋根まで飛び、四肢が同時に移り、下りの前足支持が見えなかった。記録：`artifacts/tower-contact-review/baseline/`。

## 実猫の観察

- [飼い主撮影のタワー動画](https://www.youtube.com/watch?v=jDBnX2iDZ2k)、[元記事](https://marokomama.com/rakucattower/)。高い移動の6.5–9.5秒、下降の82.3–84.2秒を追加の細かいフレームで確認。高い移動では短い跳躍と前脚の引っ掛かりがあり、後半身と尾が遅れる。下降では首・前脚を下に出して、後脚が元の板に残った状態で胴が伸びる。
- [まる・はな・みりの階段動画](https://sisinmaru.com/2021/01/26/階段を上り下りするねこ。-cats-going-up-and-down-the-stairs-（動画）/)、[動画](https://www.youtube.com/watch?v=iFiMk6qqCfo)。12–14.8秒の下降を確認。左右の前足の踏み出しに時差があり、頭・胸が先行する。上りと下りを同一の軌道の逆再生にはしない。

公開動画はローカルの観察用に使用し、アプリ・リポジトリへ動画や切り出し画像を組み込んでいない。ユーザーの猫写真の外部送信なし。

## 実際の足場と設計

実タワーメッシュの水平三角形とray pickingで面を計測。床→側面棚1.6771→箱の屋根1.829→上段ベッド2.6505を往復。高さ1.10の円形の張り出しは奥行きが浅く、箱内の面は頭上が塞がれるため四肢を安定させる経路に採用しない。透明な板や代替boxを追加していない。側面棚では上段の下に入るため姿勢を低くし、屋根では前側を通過する。

各ノードは面の範囲・身体中心・approach・exitを持ち、猫の実足幅から前後脚の接地点を作る。高さが体高の0.72倍以内なら上りはclimb、下りはstep-down。大きい床との移動だけjump-up/jump-down。

足ごとに支持位置・移動先・接地状態を保持。前足を順に置いて支持し、その後に後足を移す。胴の位置・傾きは前後の足配置から求める。頭上を避ける姿勢と、接地誤差を減らす胴の小さな補正も行う。高い移動の短い飛行区間以外は放物線でrootを動かさない。

接地中の目標位置はrootに追従させない。関節のローカル空間でCCDを解き、鏡映されたglTFルートにも対応する。骨の長さ・scaleは変更しない。板の移動が終わると実際の足位置を次の動作へ引き継ぎ、四足支持を挟んで進む。

## 2回の画像レビューと修正

1. **第1回**：48枚を撮影・画像で確認。前足支持と後足の追従は出たが、側面棚で頭が上段と重なり、棚→屋根の足が遠すぎた。上段の下での低い姿勢、屋根の前側の通過位置、下降用の足の軌道を追加した。
2. **第2回**：48枚を再撮影・画像で確認。接地の誤差は改善したが、段の切り替えで姿勢を初期化すると足位置が跳ね、上りに最大約0.07の誤差が残った。実際の接地位置を引き継ぎ、支持中の足に対する身体補正を反復するよう修正した。
3. **最終確認**：両猫・上下各20枚、計80枚を再撮影し、4枚の一覧画像すべてを実際に確認。上段に前足を置いたまま後足が屋根に残る姿勢、下降で前半身を下げる姿勢、後足の追従、四足支持を確認した。全接地点に実メッシュの面があり、接地中の足先の最大誤差はぷりん0.0333未満、こころ0.0226未満（シーン単位）。

[連続フレーム再生・比較](../artifacts/tower-contact-review/comparison.html)。`final/report.json` は足の目標・実位置・接地状態・実面の高さを保存する。キャプチャ工具は `tools/tower-contact-review/`。

## 検証と限界

ローカル単体21件、commit対象だけのクリーン構成14件が成功。両構成で型検査・Pages用build・dist audit成功。元写真はdistに含まれない。

単体検査では低い移動中の前足目標の固定、後足の上段支持、骨の長さの保存、高さ別の移動選択、全足場の往復と一時停止を確認。実GLBのブラウザ撮影ではスキニング頂点の有限性、接地面、足先誤差を検査。PC（Pages配下）・スマホ相当の長押し、移動、cancel、玩具、モード変更、手動のタワー配置の回帰検証も成功。console error/warning・HTTPエラーは各0。記録は `artifacts/direct-touch/cycle-tower-contact-desktop/report.json` と `cycle-tower-contact-mobile/report.json`。

完全な全身衝突シミュレーションではなく、肉球全体の接触面・全姿勢の自己交差を保証するものではない。タッチ検証はブラウザ環境で、実機端末ではない。
