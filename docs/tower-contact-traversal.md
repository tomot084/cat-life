# タワー移動の再作り直しと画像レビュー

2026-10-03〜04。「不自然すぎます」の指摘を受け、前回の接地検査だけでは不十分だった点を実ブラウザで再確認した。今回は関節の曲がり方、顔の向き、方向転換、実際に通れる経路を作り直した。ぷりん・こころの体格、元写真のローカル利用、既存の操作・遊び・長押し移動を保持する。

## 前回の問題を再生して確認

`retry-baseline/` に両猫の上り・下り各34枚、計136枚を保存。こころの上り2.4–4.8秒は頭を下へ折ったまま側面棚に滞在し、7.8秒付近は胴の向きが変わるのに脚が追従せずねじれる。下降3.9–5.7秒も棚の下へ身体を押し込んでいる。足先の数値が合っていても、猫の姿勢として成立していなかった。

## 経路と関節の変更

狭く頭上が塞がれる側面棚を経路から外した。**タワー手前に実際に見える支柱付きの踏み板を2枚追加**した。既存GLBの箱・上段は保持し、床→踏み板0.48→踏み板1.04→箱の屋根1.829→上段2.6505を往復する。各足の接地点はray pickingで実際の板の高さと一致するか検査する。透明な足場は使わない。

四関節を無制限に回すCCDを廃止し、`cat-limb-ik.ts` の二リンク解法に置き換えた。モデルの元の肘・膝の曲がる平面を使い、骨長を保存する。肉球の向きを身体の回転から分離して接地面に合わせる。足場内に足幅・前後間隔を含む全体の足配置を収める。

方向が大きく変わる場所では、板の上で脚を順に踏み替えてから進む。身体の向きは前後脚の位置から決める。下りの到着姿勢は下り方向を向く。胴が傾いても顔は足場を見るよう、頭の向きを独立して補正する。

低い2段は前脚を板の手前へ掛ける→体重を移す→後脚がついてくる→前脚を先へ踏み直す→四肢で安定する。下りは前脚を下へ伸ばし、後脚が上段に残る工程を持つ。接地中の足位置を固定し、身体をその足に対して動かす。後脚が到着する前に最終の前脚位置へ伸び切らないようにした。

上の大きな段差は体高の0.48倍を超えるため短い跳躍に切り替える。以前の0.72倍という判定では、小さいぷりんの四肢が届かなかった。高い段だけ短い飛行区間を持ち、前脚の接地後に後脚を乗せる。下りの飛行時間・頭の向き・踏み出しを上りから分けた。

## 画像を見て修正したサイクル

1. **retry-1：136枚。** 頭を棚の下に押し込む経路は解消したが、向き直る前に前脚を出して身体が回り、下りの到着姿勢も上り向きだった。板上の踏み替えによる方向転換と下り用の到着方向を追加した。
2. **retry-2：148枚。** 方向転換は改善したが、ぷりんの上段接地に最大0.17、下降に0.22程度のずれが出た。高すぎる段も登ろうとしていることを画像・関節位置で確認し、低い段と短い跳躍を分けた。
3. **retry-3：164枚。** 四肢のずれは改善した。横から見ると胴とともに顔が上へ向きすぎるため、頭の向きを独立させた。飛行中の後脚を「接地」と判定していた箇所も直した。
4. **足場の再配置。** 横からの画像で追加板の重なりと、下降中の脚が元の板を通る箇所を確認した。板を隣接させ、端を越えてから足を下げる軌道と、高い段から降りる前の端への接近・脚の折り畳みを追加した。最初の板の向きと床への退出方向も分けた。
5. **本番の切替修正。** 本番ではnativeアニメーションのblend中の座り／歩行姿勢がIKの基準として残っていた。0.32秒の立ち姿への切替を設け、その後にblendなしのIdleNorm基準姿勢を確定してから脚を計測する。近接した2匹が互いに離れる歩行まで止まる不具合も直した。
6. **最終：retry-final-approved、各101枚、計404枚。** 0.1秒間隔で両猫の上り・下りを再撮影。胴・顔・脚・足場を横から確認し、短い跳躍の前脚着地と遅れた後脚の着地を確認。終端で尾の姿勢を戻す際の急な切り替えもなくした。

## 検証

最終撮影では接地中の足先誤差が全フレーム0.045未満、各接地点に実際の板が存在し、その高さ差は0.035未満。頭の補正後の0.1秒間隔検査では最大誤差はぷりん上り0.0136／下り0.0235、こころ上り0.0040／下り0.0121（シーン単位）。

単体23件が成功。単体検査は支持中の足の固定、後脚が元の板に残ること、近接した猫の離脱、全足場の往復、一時停止、脚の長さ・曲がる方向・肉球の向きを確認する。commit対象だけのクリーン構成16件も成功し、Pages用build・dist auditが通った。PC／スマホ相当の長押し移動・cancel・玩具・モード切替・手動タワー配置が成功。console error／warning・HTTPエラーは各0。本番UIでの接地はPC 74回／スマホ相当73回監視し、足先の最大誤差は0.0229未満。記録：`artifacts/direct-touch/cycle-tower-retry-desktop-final/report.json`、`cycle-tower-retry-mobile-verified/report.json`。
