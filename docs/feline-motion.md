# 猫らしい上り・下り・摘まみ動作（2026-10-03）

以前のゆっくり浮くジャンプと、四足姿勢のまま浮くキャリーを改善。写真比較で調整済みの体格・長い尾を保ち、今回はGLBを変更せず、実骨格の動作制御を変更した。

- 上り：着地点を見る→後脚を深くためる→蹴り出す→空中で脚を引き寄せる→前脚を伸ばして着地→後脚と胴が追いつく。移動を重力のある弾道へ変更。こころはぷりんより重めのタイミング。
- 下り：下を見る、前へ重心を寄せる、前脚を下方へ伸ばす、前脚・後脚の順で衝撃を吸収する。背骨・耳・尾も連動。
- 摘まみ：首元を支点に胴が約67度垂れ、前脚は曲げて脱力、後脚は重力方向へ垂れる。移動速度・加速度に脚と尾が遅れて揺れる。降ろすと接地から立位へ復帰。
- 持ち上げ初期：実際の高さに応じて吊り下げへ移行し、早すぎる後脚の伸びで床を突き抜ける問題を修正。
